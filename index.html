⚙️ Sincronização

Por padrão, os dados ficam salvos somente neste navegador. Para sincronizar entre aparelhos, usamos uma planilha do Google como "banco de dados" central, via Google Apps Script.

  1. Crie uma planilha nova em sheets.new.
  2. Vá em Extensões → Apps Script.
  3. Cole o código do Apps Script.
  4. Clique em Implantar → Nova implantação → Web App.
  5. Escolha Qualquer pessoa e clique em Implantar.
  6. Copie a URL e cole na constante APPS_SCRIPT_URL.

⚠️ Trate a URL do Web App como uma senha: quem tiver o link consegue ler e alterar os dados.
